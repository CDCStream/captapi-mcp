# Security

## Reporting a vulnerability

Email **support@captapi.com** with "Security" in the subject. Include the affected endpoint or tool, steps to reproduce, and what you observed. Please do not open a public GitHub issue for security problems.

Do not include working API keys in your report. If you think a key was exposed, revoke it at [captapi.com/dashboard/api-keys](https://captapi.com/dashboard/api-keys) and create a new one.

## Scope

- The hosted MCP endpoint `https://api.captapi.com/mcp`
- The Captapi REST API at `https://api.captapi.com`
- The documentation and manifest in this repository

More details: [captapi.com/security](https://captapi.com/security).
